MAPA DO PODER · Despertar Espiral
=================================

Estrutura do repositório
------------------------
/
├── mapa-do-poder/        <- conteúdo que aparece em /mapa-do-poder
│   ├── index.html
│   ├── app.js
│   └── .htaccess
├── deploy/
│   └── mapa-do-poder.zip <- pacote para upload manual (cPanel/FTP)
└── LEIA-ME.txt

URL final
---------
https://despertarespiral.com.br/mapa-do-poder

A ferramenta é 100% estática (HTML+CSS+JS). Não precisa de servidor,
banco nem build. Todas as respostas (nome, email, telefone e respostas
dos 8 passos) ficam salvas APENAS no localStorage do navegador da
pessoa. Nada é enviado a servidores externos.


==========================================
Deploy por Git no Hostinger (recomendado)
==========================================

Esta estrutura funciona com o caminho DEFAULT do Hostinger:

1) hPanel -> domínio despertarespiral.com.br
2) Avançado -> GIT  (ou "Gerenciar repositórios Git")
3) Criar repositório:
   - URL:      https://github.com/ThalesAndrades/mapadopoder.git
   - Branch:   main
   - Caminho:  public_html        <- DEFAULT, não precisa mudar
4) Salvar -> primeiro deploy automático.
5) (Opcional) Ativar "Deploy automático" para cada push em main
   gerar pull automático no servidor.

Resultado no servidor:
   public_html/
   ├── mapa-do-poder/index.html  -> servido em /mapa-do-poder
   ├── mapa-do-poder/app.js
   ├── mapa-do-poder/.htaccess
   ├── deploy/mapa-do-poder.zip
   └── LEIA-ME.txt

URL ativa: https://despertarespiral.com.br/mapa-do-poder

ATENÇÃO sobre o site existente em public_html
---------------------------------------------
O Git deploy do Hostinger ADICIONA os arquivos do repo em public_html.
Se você já tem um site lá:
- Arquivos existentes NO repo (mesmo nome) serão sobrescritos.
- Arquivos NÃO presentes no repo seguem intactos.
Como o repo agora só tem a pasta mapa-do-poder/, deploy/ e LEIA-ME.txt,
seu site principal em public_html/index.html etc. permanece intocado.


===================================
Deploy manual (sem Git)
===================================

1) Baixe deploy/mapa-do-poder.zip
2) hPanel -> File Manager -> public_html
3) Crie a pasta "mapa-do-poder" dentro de public_html (se não existir)
4) Faça upload do ZIP, descompacte dentro dessa pasta
5) Acesse https://despertarespiral.com.br/mapa-do-poder


==========================================
Onde ficam os dados da pessoa
==========================================

Por padrão (CAPTURE_ENDPOINT = "" no topo do app.js):
- Respostas dos 8 passos -> localStorage do navegador
- Nome, e-mail, telefone (etapa opcional ao fim) -> localStorage

Ninguém mais vê esses dados. Sem banco, sem envio externo.

Quer receber os contatos por e-mail? (opcional)
-----------------------------------------------
1) Crie conta no Formspree (https://formspree.io) ou similar.
2) Pegue a URL do endpoint (ex.: https://formspree.io/f/SEU_ID).
3) Em mapa-do-poder/app.js, edite:

      const CAPTURE_ENDPOINT = "";

   para:

      const CAPTURE_ENDPOINT = "https://formspree.io/f/SEU_ID";

4) Commit + push. Hostinger atualiza no próximo deploy.
