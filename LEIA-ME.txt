MAPA DO PODER · Despertar Espiral
=================================

O que é este repositório
-------------------------
Página única, interativa e imersiva da ferramenta "Mapa do Poder".
100% estática (HTML + CSS + JavaScript). Não precisa de servidor,
banco de dados nem build. Todas as respostas (nome, email, telefone
e respostas dos 8 passos) ficam salvas APENAS no navegador da pessoa
(localStorage) — nenhum dado é enviado para servidores externos.

Arquivos
--------
- index.html   -> a página
- app.js       -> lógica (passos, resultado, captura, animações)
- .htaccess    -> cache, compressão e segurança básica (Apache)
- LEIA-ME.txt  -> este arquivo
- deploy/      -> ZIP pronto para upload manual via cPanel/FTP

URL final
---------
https://despertarespiral.com.br/mapa-do-poder


==========================================
Deploy por Git no Hostinger (recomendado)
==========================================

1) Entre no hPanel do Hostinger.
2) No domínio despertarespiral.com.br, vá em:
   Avançado -> GIT  (ou "Acessar gerenciador Git")
3) Clique em "Criar repositório":
   - Repositório:  https://github.com/ThalesAndrades/mapadopoder.git
   - Branch:       main
   - Caminho do repositório:  public_html/mapa-do-poder
4) Salvar. Hostinger faz o primeiro deploy automaticamente.
5) (Opcional) Configure "Deploy automático" para que cada push em main
   gere um pull automático no servidor. Ou clique em "Implementar"
   manualmente sempre que quiser atualizar.

Pronto: https://despertarespiral.com.br/mapa-do-poder está no ar.

Se precisar atualizar a ferramenta:
   git add . && git commit -m "ajustes" && git push origin main
   -> Hostinger detecta o push e atualiza (se auto-deploy estiver ativo)


===================================
Deploy manual (cPanel / FTP / drag)
===================================

Se preferir não usar Git:

1) Baixe deploy/mapa-do-poder.zip
2) Acesse o "File Manager" do Hostinger (em public_html)
3) Crie a pasta "mapa-do-poder" dentro de public_html
4) Faça upload do ZIP, descompacte dentro dessa pasta
5) Acesse https://despertarespiral.com.br/mapa-do-poder


==========================================
Onde ficam os dados da pessoa
==========================================

Por padrão (CAPTURE_ENDPOINT = "" no topo do app.js), tudo fica
salvo APENAS no localStorage do navegador da pessoa:
- respostas dos 8 passos
- nome, e-mail, telefone (último passo)

Ninguém mais vê esses dados. Não há banco, não há envio externo.

Quer receber os contatos por e-mail (opcional)?
-----------------------------------------------
1) Crie uma conta gratuita no Formspree (https://formspree.io)
   ou similar (Google Forms, RD Station, Mailchimp).
2) Pegue a URL do endpoint (ex.: https://formspree.io/f/SEU_ID).
3) No arquivo app.js, edite a linha:

      const CAPTURE_ENDPOINT = "";

   para:

      const CAPTURE_ENDPOINT = "https://formspree.io/f/SEU_ID";

4) Commit + push (se Git deploy) ou re-upload manual.

Os contatos passarão a ser enviados para o endpoint além de ficarem
salvos no navegador.


===================
Personalização
===================
- Texto dos 8 passos:  variável STEPS no topo do app.js
- Texto do ritual:     variável RITUAL_TEXT no app.js
- Texto da síntese de resultado:  função renderResult() no app.js
- Cores e fontes:      bloco :root no início do index.html
- Voz do ritual:       Web Speech API do próprio dispositivo


===================
Manutenção
===================
Mantenha sempre index.html e app.js juntos, no mesmo diretório.
