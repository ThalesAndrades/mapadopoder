Como funciona

8 passos para mapear sua trava

Cada passo é uma pergunta curta. No final, você recebe um mapa personalizado com o que descobriu — pronto para guardar e revisitar.

①
Responda no seu ritmo. Pode pausar, voltar, refazer. O progresso fica salvo sozinho.
②
Receba seu mapa. Uma leitura personalizada das suas respostas — para você usar quando quiser.
③
100% privado. Tudo fica salvo só neste dispositivo. Nada é enviado para servidores externos.
